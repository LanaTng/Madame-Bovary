# Les thèmes de l'oeuvre

Madame Bovary est un roman qui aborde de nombreux thèmes, explorant le caractère humain et les comportements sociétaux.



Thèmes principaux :
1. L'amour
2. L'adultère
3. La fiction comme échappatoire
4. La désillusion
5. La critique sociale
